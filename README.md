# Inconsistent effects of P enrichment and predator presence on food-web dynamics in a bromeliad system
This project aimed to test a conceptual integration of two disparate fields of ecology: food web topology and ecological stoichiometry. We simultaneously manipulate resource stoichiometry and food web structure, in two different countries, to test predicted changes in interaction strength, measured through biomass loss/accumulation
